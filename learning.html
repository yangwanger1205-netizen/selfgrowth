2026-11-09 网页结构

用独立页面组织成长主页

学了什么
用独立的 HTML 文件和相对链接实现页面之间的导航。
遇到的问题
评审要求至少三个可互跳的页面。先前的单文件练习通过 URL 参数切换视图，提交后只算一个页面文件。
怎么处理
把成长主页拆成首页、学习记录和技能与项目三个文件。每页使用相同的导航链接，并标记当前所在页面。
2026-11-09 前端交互

让失物记录刷新后还能找到

学了什么
用 localStorage 保存记录，用物品名称和丢失地点筛选列表。
遇到的问题
发布后要保留数据。列表要隐藏手机号的中间四位，详情又要能按需显示完整号码。
怎么处理
把记录转为 JSON 存入浏览器，加载时重新读取。列表调用脱敏函数，详情由按钮控制完整号码的显示。评审验证了刷新、搜索和脱敏行为。
2026-11-09 提交验收

按评审要求检查交付文件

学了什么
提交前核对入口、样式、脚本和项目说明，逐项对照评审要求。
遇到的问题
失物招领练习第一次只提交了 CSS。评审能看到样式，却无法验证表单、存储和搜索。
怎么处理
失物招领练习改交包含 HTML、CSS 和 JavaScript 的完整文件。成长主页则使用多文件仓库，并随源码提交 README、首页截图和更新计划。
